Inheritance

Reusability and types of inheritance

What is Inheritance?

Inheritance allows a new class (subclass or child class) to acquire the properties and methods of an existing class (superclass or parent class). This mechanism enables code reusability and establishes a natural hierarchy between objects.

Real-World Analogy: Animals

A Dog IS-A Animal. The Animal class might have properties like age and methods like eat(). Instead of rewriting these for the Dog class, the Dog class can inherit them from Animal, and then add its own specific methods like bark().

Inheritance Hierarchy

Animal eat(), sleep()
Dog bark()
Cat meow()

Using 'extends' in Java

Java 
// Parent Class
class Animal {
    public void eat() {
        System.out.println("I can eat");
    }
}

// Child Class
class Dog extends Animal {
    public void bark() {
        System.out.println("I can bark");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog myDog = new Dog();
        myDog.eat();  // Inherited from Animal
        myDog.bark(); // Defined in Dog
    }
}

Types of Inheritance

  • Single: Class B extends Class A.
  • Multilevel: Class C extends Class B, which extends Class A.
  • Hierarchical: Class B and Class C both extend Class A.
  • Note: Java does not support Multiple Inheritance with classes (Class C cannot extend both Class A and Class B) to avoid the "Diamond Problem". It uses Interfaces for this instead.
Common Interview Questions

Q: What is the 'super' keyword?
A: The super keyword is a reference variable used to refer to the immediate parent class object. It can be used to call parent class methods, variables, and constructors.

Q: Why is multiple inheritance not supported in Java?
A: To avoid ambiguity (The Diamond Problem). If two parent classes have methods with the same name, the compiler wouldn't know which one the child class should inherit.
