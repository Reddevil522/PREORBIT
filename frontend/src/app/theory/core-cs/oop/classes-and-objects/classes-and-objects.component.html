Classes and Objects

Understanding classes, objects, and instantiation

Class (The Blueprint)

A class is a user-defined blueprint or prototype from which objects are created. It represents the set of properties or methods that are common to all objects of one type.

  • Logical entity
  • Does not consume memory
  • Declared once
Object (The Instance)

An object is a basic unit of Object-Oriented Programming and represents the real-life entities. It is an instance of a class.

  • Physical/Runtime entity
  • Consumes memory when created
  • Can be instantiated multiple times

Real-World Analogy: Building a House

A Class is like an architect's blueprint for a house. It defines where the rooms, doors, and windows go, but it is not a physical house you can live in.

An Object is the actual physical house built from that blueprint. You can build many houses (Objects) from the exact same blueprint (Class).

Defining a Class and Creating an Object

Java 
// 1. Defining the Class
class Dog {
    String name;
    int age;

    void bark() {
        System.out.println(name + " says Woof!");
    }
}

public class Main {
    public static void main(String[] args) {
        // 2. Creating an Object (Instantiation)
        Dog myDog = new Dog(); 
        
        // 3. Accessing state and behavior
        myDog.name = "Buddy";
        myDog.age = 3;
        myDog.bark(); // Output: Buddy says Woof!
    }
}

Memory Allocation

  • When a class is defined, no memory is allocated.
  • Memory is allocated on the Heap when the new keyword is used to create an object.
  • The reference variable (like myDog) is stored on the Stack and points to the object on the heap.
Common Interview Questions

Q: What is the difference between a class and an object?
A: A class is a template or blueprint. An object is a physical instance of that class that consumes memory.

Q: What does the 'new' keyword do?
A: It allocates memory at runtime for the object on the heap and returns a reference to it.
