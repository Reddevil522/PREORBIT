Encapsulation

Data hiding and getters/setters

Data Hiding

Encapsulation is the mechanism of wrapping the data (variables) and code acting on the data (methods) together as a single unit. In encapsulation, the variables of a class are hidden from other classes, and can only be accessed through the methods of their current class.

Real-World Analogy: A Medical Capsule

A capsule hides the actual medicine inside it. You don't interact with the powder directly; you swallow the capsule, and it does its job safely. Similarly, a class hides its variables and provides safe methods (like getters and setters) to interact with them.

The Encapsulation Shield

Public Methods (Getters/Setters)
Private Data Hidden from outside world

Achieving Encapsulation in Java

Java 
class BankAccount {
    // 1. Private data variables
    private double balance;

    // 2. Public getter method
    public double getBalance() {
        return balance;
    }

    // 3. Public setter method with validation
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        } else {
            System.out.println("Invalid amount");
        }
    }
}

Benefits of Encapsulation

  • Control: You have full control over the data (e.g., preventing negative account balances).
  • Security: Data is hidden from external classes, preventing accidental modification.
  • Flexibility: Internal implementation can be changed without breaking external code.
Common Interview Questions

Q: How do you achieve encapsulation in Java?
A: By declaring the variables of a class as private and providing public setter and getter methods to modify and view the variables.

Q: What is data hiding?
A: Data hiding is a feature of OOP that prevents direct access to data members of a class. It is the core concept behind encapsulation.
