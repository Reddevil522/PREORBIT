Introduction to OOP

Basic concepts and paradigms of Object-Oriented Programming

What is Object-Oriented Programming?

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects", which can contain data (attributes or properties) and code (methods or behaviors). Instead of writing procedures or functions that perform operations on data, OOP allows you to create objects that encapsulate both data and operations.

Procedural vs. Object-Oriented

Procedural Programming
  • Focuses on functions and processes
  • Data and functions are separate
  • Top-down approach
  • Harder to maintain for large codebases
Object-Oriented Programming
  • Focuses on data (objects)
  • Data and methods are encapsulated together
  • Bottom-up approach
  • Highly scalable and maintainable

Real-World Analogy

Think of a Car. In the real world, a car has attributes (color, brand, speed) and behaviors (accelerate, brake, honk). In OOP, we define a Car class as a blueprint, and every actual car (like your specific red Toyota) is an object created from that blueprint.

A Simple Java Class

Java 
public class Car {
    // Attributes (Data)
    String color;
    int maxSpeed;

    // Behavior (Methods)
    public void accelerate() {
        System.out.println("The car is accelerating...");
    }
}

Key Takeaways

  • OOP makes code reusable and easier to maintain.
  • It mimics real-world entities, making complex systems easier to understand.
  • Java is fundamentally an Object-Oriented language, meaning everything revolves around classes and objects.
Common Interview Questions

Q: What are the four pillars of OOP?
A: Encapsulation, Inheritance, Polymorphism, and Abstraction.

Q: Why use OOP over Procedural programming?
A: OOP provides better data security, reusability, and makes large codebases easier to manage.
