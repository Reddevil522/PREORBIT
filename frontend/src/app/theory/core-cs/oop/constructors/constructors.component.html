Constructors

Types of constructors and object initialization

What is a Constructor?

A constructor in Java is a special block of code similar to a method that is called when an instance of an object is created. Unlike methods, constructors have the exact same name as the class and do not have a return type.

Real-World Analogy: Car Factory

When a new car rolls off the assembly line, it needs to be painted, given a serial number, and filled with a little bit of gas before it can be used. A constructor is like that final assembly step—it sets the initial values (color, serial number) for a brand new object.

Default Constructor

A constructor with no arguments. If you don't write any constructor, Java provides an invisible default one.

public Dog() {}
Parameterized Constructor

A constructor that accepts parameters, allowing you to pass specific values to initialize the object's fields immediately.

public Dog(String name) {}

Using Constructors in Java

Java 
class Student {
    String name;
    int age;

    // 1. No-arg (Default) Constructor
    public Student() {
        System.out.println("Student created with no data");
    }

    // 2. Parameterized Constructor (Overloading)
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println(name + " created!");
    }
}

public class Main {
    public static void main(String[] args) {
        // Calls the no-arg constructor
        Student s1 = new Student(); 
        
        // Calls the parameterized constructor
        Student s2 = new Student("Alice", 20); 
    }
}

Rules of Constructors

  • Constructor name must be the same as its class name.
  • A constructor must have no explicit return type (not even void).
  • A Java constructor cannot be abstract, static, final, or synchronized.
  • You can use the this() keyword to call another constructor in the same class (Constructor Chaining).
